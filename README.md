# Bank-Reports

📌 Project Overview

This project is an interactive Customer Churn Analysis Dashboard developed in Microsoft Power BI. The dashboard helps businesses identify customer churn patterns, analyze customer engagement, and evaluate risk factors that influence customer retention.

The project is divided into three analytical dashboards:

Customer Churn Dashboard
Engagement Analysis Dashboard
Risk Analysis Dashboard

The dashboards provide valuable insights into customer behavior using interactive filters, KPIs, and visualizations.


🛠 Tools & Technologies Used
Microsoft Power BI
Power Query (Data Cleaning & Transformation)
DAX (Data Analysis Expressions)
Data Modeling
Interactive Slicers
KPI Cards
Charts & Visualizations


📈 Business Insights
Overall customer churn rate is 20.37%.
Germany and France experience the highest churn.
Customers aged 46–55 are more likely to leave.
Inactive customers have significantly higher churn than active customers.
Poor credit scores are strongly associated with higher churn.
High-balance customers require targeted retention strategies.
Customer engagement is a key driver of retention.
